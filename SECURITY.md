# Security policy

Only `main` is supported.

These VMs are throwaway labs. Default credentials and auto-login are intentional, so don't expose them to untrusted networks.

For anything else, don't open a public issue. Report it privately via [GitHub security advisories](https://github.com/georgitinchev/vm-lab-configs/security/advisories/new). Expect a reply within 7 days.
